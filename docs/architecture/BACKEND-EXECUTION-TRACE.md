## 2. Dynamic Hardware Detection & CPU vs GPU Semantics

The centralized hardware provider dynamically queries the host hardware via `nvidia-smi` with caching to prevent redundant process overhead:

- **GPU AI Inference**: For Ollama LLM execution on the local GPU:
  ```
  ✓ Hardware:
    Ran on NVIDIA RTX 2050
  ```
- **CPU Compute Operations**: For CPU-only operations (Python OCR, PDF extraction, Pandas, NumPy, text tokenization):
  ```
  ✓ Hardware:
    Ran on CPU
  ```
- **Hybrid Vision & Analytics**:
  ```
  ✓ Hardware:
    AI Inference: Ran on NVIDIA RTX 2050 · Compute: CPU
  ```
