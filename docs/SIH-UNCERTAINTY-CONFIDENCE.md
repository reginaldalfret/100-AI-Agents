## 1. Explicit Epistemic Uncertainty States

To prevent hallucinations and false certainty, the engine tags each finding with one of 6 formal epistemic states:

1. **`FACT`**: Direct empirical reading from verified NDT scan or sensor.
2. **`INFERENCE`**: Logical derivation based on regulatory standards.
3. **`MISSING`**: Required parameter absent from the dataset (triggers replan/inquiry).
4. **`CONFLICT`**: Diverging values across independent inspection reports.
5. **`UNCERTAIN`**: Degraded image quality or low signal-to-noise ratio.
6. **`ESTIMATE`**: Extrapolated mathematical projection calculated in the Python sandbox.

---

## 2. Calibrated Confidence Scoring

Rather than outputting opaque percentages, confidence is computed dynamically based on:
- Source corroboration count
- Zero active data conflicts
- Evidence completeness checklist
- Image visual clarity
- Sandbox mathematical verification

**Output:** `HIGH`, `MEDIUM`, or `LOW` accompanied by explicit explanatory factors.
