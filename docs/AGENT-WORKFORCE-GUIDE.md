# Super AI — 101 Specialist Agent Workforce Guide

Welcome to **Super AI**, the sovereign, on-premise AI workbench featuring **101 specialized AI agents** powered by local open-weight neural engines with **zero cloud data egress**.

---

## 1. What is Super AI (Agent 101)?

**Agent 101 (Super AI)** is the master AI orchestrator. When you give Super AI a complex or multi-step goal (such as *"Build a complete web application with authentication and database"* or *"Investigate this technical document and generate a verified executive report"*), Super AI:
1. **Deconstructs** your prompt into discrete task steps.
2. **Assigns** the best specialist agents (e.g. Coding, UI/UX, Security, Testing, Document).
3. **Routes** execution to optimal local models (Nemotron 3 for reasoning, Gemma 3 for vision, Qwen 2.5 Coder for programming).
4. **Synthesizes** the individual outputs into a unified, verified deliverable.

You do not need to orchestrate the specialist agents manually—Super AI coordinates them autonomously.

---

## 2. What are the 100 Specialist Agents (001–100)?

The 100 specialist agents are purpose-built experts designed for specific technical, operational, and analytical tasks. Each specialist has:
- A **numeric identifier** (`001` to `100`).
- A **clear, technology-oriented role name** (e.g. `Writing Agent`, `Coding Agent`, `SQL Agent`, `Image Analysis Agent`).
- A **high-level category** for instant filtering.
- **3 to 5 example prompts** to help you get started immediately.

## 4. How Does Model Routing Work?

Super AI operates with **three specialized local models** running on-premise:

1. **NVIDIA Nemotron 3 Nano (4B)**:
   - *Specialty*: Deep reasoning, multi-agent orchestration, complex logic, and document synthesis.
   - *Assigned to*: Super AI, Research, Planning, Security, Business Analysis.

2. **Google Gemma 3 (4B Multimodal)**:
   - *Specialty*: Vision, document OCR, visual diagram QA, and multimodal inspections.
   - *Assigned to*: Document Agent, PDF Agent, OCR Agent, Image Analysis Agent.

3. **Qwen 2.5 Coder (1.5B)**:
   - *Specialty*: Code generation, debugging, SQL queries, spreadsheet formulas, and data parsing.
   - *Assigned to*: Coding Agent, Python Agent, JavaScript Agent, SQL Agent, DevOps Agent.

When in **Auto Mode**, Super AI selects the right model dynamically based on task requirements. You can also override the model directly in the chat composer dropdown.

## 5. How Users Choose an Agent

- **If your task is general or multi-faceted**: Start with **101 Super AI**.
- **If you need a specific programming task**: Select **003 Coding Agent**, **032 Python Agent**, or **043 React Agent**.
- **If you need an image or scanned document analyzed**: Select **066 Image Analysis Agent** or **065 OCR Agent**.
- **If you need to analyze tabular data or write SQL**: Select **005 Data Analysis Agent** or **031 SQL Agent**.
- **If you need a quick search**: Type in the top search bar (e.g. `Python`, `Image`, `Resume`, `042`) to instantly filter the workforce.
